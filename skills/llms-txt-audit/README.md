# llms-txt-audit

**Agent skill: audit any website for `llms.txt` presence, freshness, and validity; generate a compliant `llms.txt` from site content if missing or stale.**

Works with **Claude Code**, **Cursor**, **Codex**, **OpenCode**, and any agent that reads `SKILL.md`.

---

## What it does for you

| Problem | Solution |
|---------|----------|
| Your site has no `llms.txt` — AI crawlers see nothing | **Audit + generate** a standards-compliant `llms.txt` from your content |
| Your `llms.txt` is stale (months old) | **Freshness check** flags it; optionally regenerates from live pages |
| Your `llms.txt` has broken links or invalid structure | **Full validation** — HTTP reachability, spec compliance, link health |
| You don't know if your site is LLM-readable | **Crawl report** shows exactly what an AI would find |

## Quick Start

### As an Agent Skill (recommended)

```bash
# Claude Code
git clone https://github.com/romankurnovskii/llms-txt-audit-skill ~/.config/claude-code/skills/llms-txt-audit

# Cursor
git clone https://github.com/romankurnovskii/llms-txt-audit-skill ~/.cursor/skills/llms-txt-audit

# Codex
git clone https://github.com/romankurnovskii/llms-txt-audit-skill ~/.codex/skills/llms-txt-audit

# OpenCode
git clone https://github.com/romankurnovskii/llms-txt-audit-skill ~/.opencode/skills/llms-txt-audit
```

Then invoke in your agent:
> "Audit example.com for llms.txt and generate one if missing"

### As a Standalone CLI

```bash
pip install httpx beautifulsoup4 lxml markdownify
python scripts/audit_llms_txt.py --url https://example.com --generate
```

## Features

- **Standard-compliant** — Follows the [llms.txt specification](https://github.com/llmstxt/llmstxt)
- **Respects `robots.txt`** — Ethical crawling by default
- **Freshness-aware** — Flags files older than your threshold (default 30 days)
- **Link validation** — HEAD checks every URL in existing `llms.txt`
- **Smart selection** — Prioritizes homepage, docs, API, guides, blog
- **Attribution built-in** — Every generated file credits the source method
- **Zero-config defaults** — Works out of the box; all parameters optional

---

## Configuration Options

| Option | Default | Description |
|--------|---------|-------------|
| `--max-pages` | 50 | Max pages to crawl |
| `--check-freshness-days` | 30 | Flag as stale if older |
| `--generate` | false | Auto-generate if missing/stale |
| `--output` | `./llms.txt` | Output path for generated file |
| `--respect-robots` | true | Obey robots.txt |
| `--timeout` | 10s | HTTP request timeout |
